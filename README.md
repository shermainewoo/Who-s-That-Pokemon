# Who-s-That-Pokemon
Simple pokemon guessing game created with HTML, CSS and Javascript! 

Check out the website [here!](https://github.com/shermainewoo/Who-s-That-Pokemon)

## Features
Fetches data from PokeAPI for users to match an image to its correct name. Allows for users to select what generations to be tested on.
